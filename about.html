关于 Angles

一个 MIT 开源的编码 Agent 项目，把分发问题压缩成一个文件

1.6 MB 单文件体积
30+ 内置工具
11 模型供应商
5 预编译平台
0 运行时依赖
MIT 开源许可证

为什么要做成单个二进制

现在大多数 agentic 编码工具以 Node 或 Python 包的形式分发，会拉进成百上千个传递依赖，或者做成体积庞大的多层安装器。这在普通开发机上没问题——直到你想把它放到一台 ARM64 单板计算机、一个无 root 权限的容器里，或者 iOS 上的 iSH 环境里。

Angles 编译成一个静态二进制，零运行时依赖。分发问题就塌缩成一句话："下载一个小于 2MB 的文件，然后 chmod +x"。

和其他工具的区别

  • 不依赖 Node / Python / 解释器，原生静态二进制直接运行
  • 安装体积从几十 MB 加一棵依赖树，变成不超过 2 MB 的单个文件
  • 不需要为了用而先装一整套工具链
  • 在 ARM64 单板机、无 root 容器、iSH 里都能跑起来

本地优先

配置和 API 密钥都留在你自己的机器上（~/.angles/），请求直接从你的设备发往模型供应商。Angles 帮你写代码，但不会带走你的秘密。

先给出计划再动手

从 v0.4.1 起，Angles 在执行前列出高层操作步骤（读取… 安装… 创建… 编辑… 运行…），让你在执行之前就知道它准备做什么，再决定是否放行。
