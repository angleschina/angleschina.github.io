包管理器安装

已装 Node.js 的话，npm 是更省事的方式。

> npm i -g @angleschina/angles > angles install

需要 Rust 工具链（stable 即可）。仓库根目录提供 Makefile 与 Cross.toml，可直接交叉编译。

# 克隆与构建 $ git clone https://github.com/angleschina/angles-cli.git $ cd angles-cli $ cargo build --release # 安装 $ cp target/release/angles ~/.local/bin/ # 交叉编译（需先 make setup-*） $ make arm64 # Linux ARM64 $ make x64 # Linux x64 $ make macos-arm64 # macOS ARM64（仅 macOS）
📦

方式二：通过 npm 安装

全局安装后一条命令即可完成二进制下载、校验与安装，自动匹配你的平台架构。

# 全局安装 $ npm i -g @angleschina/angles # 安装对应平台的二进制（自动识别系统与架构） $ angles install ✓ installed → ~/.local/bin/angles # 验证 $ angles --version

npm 包名：@angleschina/angles · 也可用 npx @angleschina/angles 免安装运行。

🧭

安装指南

1

选择安装方式

有 Node 环境就用 npm；没有就用预编译二进制，解压后 tar xzf angles-*.tar.gz 得到一个可执行文件。

2

放到 PATH 里

把二进制移到 ~/.local/bin/ 或 /usr/local/bin/，然后 chmod +x angles。

3

配置模型供应商

运行 angles config 写入 API 密钥与模型名，配置保存在 ~/.angles/config.json。也可用 angles gateway 走交互式向导。

4

开始使用

angles chat 进入交互式对话；angles exec "指令" 非交互式执行单条指令；angles serve -p 8801 启动本地 HTTP 网关与控制台。
