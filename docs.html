安装

两种方式：npm 一步到位，或直接下载对应平台的静态二进制。

# 方式一：npm（推荐）
npm i -g @angleschina/angles && angles install

# 方式二：手动安装二进制
tar xzf angles-linux-arm64.tar.gz
chmod +x angles-linux-arm64
mv angles-linux-arm64 ~/.local/bin/angles

# 验证
angles --version

如果 ~/.local/bin 不在 PATH 中，把它加进去：export PATH="$HOME/.local/bin:$PATH"，并写进 ~/.bashrc 或 ~/.zshrc。

配置模型

Angles 支持多家模型供应商，配置全部保存在本机，密钥不会经过任何中转服务器。

# 查看当前配置
angles config

# 交互式向导（推荐首次使用）
angles gateway

# 配置文件位置
~/.angles/config.json

配置项包含：供应商、API 地址、模型名、API 密钥、最大 token、Agent 人设、搜索引擎、审批策略等。

常用命令

angles chat              # 交互式对话（默认模式）
angles exec "指令"        # 非交互式执行单条指令后退出
angles gateway           # 设置向导（TUI 交互式）
angles serve -p 8801     # 启动本地 HTTP 网关（API + Web 控制台）
angles config            # 显示当前配置
angles doctor            # 诊断安装与配置
angles history           # 查看历史会话
angles resume            # 恢复历史会话
angles plan              # 生成当前任务的操作说明计划
angles update            # 检查并更新 Angles CLI
angles skill             # 管理 Skill（安装、创建、删除）

内置工具

Angles 不依赖模型临时拼凑 shell 命令，而是绑定了一套确定性的工具集，共 30+ 个，模型通过函数调用驱动它们。

文件与目录

  • angles-createfile · angles-writefile · angles-appendfile · angles-insertline — 创建、覆盖、追加、插入
  • angles-readfile · angles-head · angles-tail — 读取全文 / 开头 / 末尾
  • angles-deletefile · angles-deleteline · angles-copyfile · angles-movedir — 删除与移动
  • angles-mkdir · angles-ls · angles-tree · angles-fileinfo — 目录与元信息

搜索与编辑

  • angles-searchfile · angles-grep — 按文件名 / 按内容搜索
  • angles-replace · angles-replaceall — 替换首次出现 / 全部替换

终端与网络

  • angles-run · angles-runbg · angles-kill — 执行、后台执行、终止进程
  • angles-pwd · angles-cd — 工作目录
  • angles-fetch · angles-websearch · angles-fetchpage — 下载、搜索、抓取正文

Git

  • angles-gitinit · angles-gitcommit · angles-gitlog · angles-gitdiff · angles-gitbranch

联网搜索

angles-websearch 支持限定站点、文件类型、排序方式与时间范围，返回结构化结果（标题、链接、域名、摘要、发布时间）。

// 模型调用示例：限定 GitHub 上最近一周的内容
{
  "query": "rust async runtime",
  "site": "github.com",
  "time_range": "week",
  "sort": "date"
}

// 查找 PDF 文档
{ "query": "transformer survey", "filetype": "pdf" }

搜索服务需要密钥时，设置环境变量 UAPI_API_KEY；未配置则回落到访客额度。

本地网关

angles serve 会在本机起一个 HTTP 服务，提供 API 接口和浏览器控制台，端口默认 8801。

angles serve -p 8801
# → http://127.0.0.1:8801

适合把 Angles 接到其他工具、脚本或前端界面上使用。服务只监听本机，默认不对外暴露。

常见问题

启动时报找不到命令？

确认二进制在 PATH 里，且已 chmod +x。用 angles doctor 可以一次检查二进制、配置文件、API 连通性与依赖。

macOS 提示"无法验证开发者"？

执行 xattr -d com.apple.quarantine ./angles 清除隔离标记，或在「系统设置 → 隐私与安全性」中选择仍要打开。

密钥安全吗？

配置与密钥只存在本机 ~/.angles/ 目录，请求直接从你的机器发往模型供应商，不经过 Angles 的任何服务器。

支持哪些模型？

内置 OpenAI / Claude / Gemini / DeepSeek / Grok / Qwen / GLM / Kimi 等 11 家供应商，也可填任意 OpenAI 兼容地址。

能离线用吗？

工具本身零依赖、可离线安装，但模型推理需要联网（除非你接本地模型服务）。
