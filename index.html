核心特性

够用的能力，极简的分发

📦

单文件分发

1.6 MB 静态二进制，不含 Node / Python / 动态库。下载一个文件、chmod +x 就能跑，SBC、容器、无 root 环境都行。

🧩

30+ 内置工具

文件、目录、终端、Git、网络六大类工具全在本机执行，模型只在需要时才出境。不做一次性 shell 拼接。

🤖

11 家模型供应商

OpenAI、Claude、Gemini、DeepSeek、Grok、Qwen、GLM、Kimi……随时切换。密钥只留在 ~/.angles/，不过任何中转服务器。

📋

先出计划再动手

每次执行前列出高层操作步骤（读取…安装…创建…编辑…运行…），你能提前看到它准备做什么，再决定放不放行。

🌐

联网搜索与抓取

内置聚合搜索接口，支持 site: / filetype: 限定与时间范围过滤；可抓取任意页面正文，交给模型阅读。

🖥️

多平台预编译

Linux ARM64/x64、macOS ARM64/x64、Windows x64 五个平台的二进制由 CI 在每次打 tag 时自动产出。

快速开始

几分钟就能跑起来

1

安装

通过 npm 安装，或直接从 Releases 下载对应平台的压缩包。

npm i -g @angleschina/angles

2

配置模型

写入 API 密钥与模型名，配置保存在本地 ~/.angles/。

angles config

3

开始编码

交互式对话，或非交互式执行单条指令后退出。

angles chat
